# deep-coo-cloud 插件介绍

> **让 Coo 桌宠拥有云端人格** —— 本机 DSH 控制台 × 云端 DSH 人格 × 桌面桌宠，一套人格、一份记忆、一种心情，随时跨端接得上话。

![封面](images/01-cover.png)

## 这是什么

**deep-coo-cloud** 是一个 DeepSeek Harness（DSH）插件，把「桌面上的 Coo 桌宠」「本机的 DSH 控制台」「云服务器上的 DSH 人格」串成同一个她：

- 桌宠（Coopanion）负责**被看见、被触摸、说话**；
- 本机 DSH Web UI 里的 **deep-coo-cloud 面板** 负责**聊天、总控台、设置、Coo 市场、桌宠 DIY**；
- 云服务器上的 DSH 会话负责**人格、角色卡、记忆、心情**，并通过 QQ 桥接与 QQ 里的她共用同一份人格。

所有入口共享同一份角色卡、同一份 deep-soul 记忆、同一份实时情境，因此你可以在 QQ 上说一句、回到本机面板接着聊——她接得上。

![核心特性](images/02-features.png)

## 核心特性

### 1. 一个侧栏，四个面板

左侧栏只有一个入口（默认名「鲸歌」，可在设置里改名），内部四个 Tab：

| Tab | 作用 |
| --- | --- |
| **聊天** | 与云端会话实时聊天；`/events` 推送新消息，断线自动重连 |
| **总控台** | bridge/服务器/QQ 桥/桌宠/心情状态卡片、本机情境流、QQ 近况、组件状态、一键暂停观察 |
| **设置** | 通用/连接（名称、标题、桥接地址、服务器 SSH）、面板选项、情境观察开关、QQ 预览配置、桌宠 DIY、Coo 市场下载设置 |
| **Coo 市场** | 浏览/搜索/下载 Coo 社区 Cortico 扩展（npm），一键下载到本机；安装到 Coopanion 需二次确认 |

### 2. 人格同调：一个人，不是两个

- 同一角色卡：所有会话（面板 / 桌宠 / QQ / 服务器 Web）使用同一份角色卡
- 同一记忆/心情：deep-soul 单一 `mind.db`，桌宠气泡动作跟随心情
- 同一实时情境：本机前台窗口 + 本机 DSH 活跃会话 → 服务器共享情境 → 注入**所有**鲸歌会话
- 跨端对话：本机/面板最近对话 ↔ QQ 私聊/群聊最近对话互相注入，用于自然接话

### 3. 控制台可自定义

左侧栏名称、面板标题、Tab 文案、桥接地址、服务器 SSH 主机、服务器 patch 路径、QQ 群/私聊白名单、刷新间隔、区块显示、气泡字号、发送键……都在「设置」里改，保存在本机 `settings.json`，不进入分发包。

### 4. 桌宠 DIY

- 形象包：内置 **whale**（DeepSeek 大肥鱼/女仆）与 **coo**（蓝色 Coo），也可自动发现 Coopanion 里安装的用户形象包 / Steam Workshop 包
- 外观轴：配色、服装、头顶、耳侧配件、眼镜、颈饰（随形象包定义）
- 导入形象包：设置 → 桌宠 DIY 支持上传 **Coo 形象包 ZIP**（≤128MB，安全解包、不执行包内代码）
- 总控台「本机桌宠插件」：前台感知/游戏陪玩、跨端接话、桌宠 DIY 状态集中展示（保留远程人格与 QQ 同一身份）；Coopanion 扩展另折叠
- 换装页快捷栏：`/dress` 地板 6 个图标可点 —— 主程序 / 形象包目录 / Coopanion 官网 / 网页邮箱 / 音效开关 / DSH 面板（`dshPanelUrl` 可配）
- 尺寸与界面：scale 0.5–3、气泡大小/字号/速度、光晕、明暗主题、走位、音效、悬停按钮
- 保存后约 1 秒热生效，不需要重启 DSH

### 5. 隐私与可分发

源码层已**去私有化**：不含真实云服务器 IP/域名、QQ 号、本机路径、SSH 私钥、token 等默认值。打包流水线还会再做一次脱敏 + 构建后隐私扫描，**0 命中才允许发布**。

## 组件

| 组件 | 作用 | 必需 |
| --- | --- | --- |
| `deep-coo-cloud/`（原 whale-panel） | DSH 面板插件：聊天 / 总控台 / 设置 / Coo 市场 / 桌宠 DIY | ✅ |
| `bridge/` | 本机桥接服务：连服务器、提供历史/实时事件/心情/情境/市场代理 | 用云端人格时必需 |

| `server/` | 服务器侧共享情境注入插件 + 本机同步器 | 可选 |

## 快速开始

1. **安装面板**：`plugin_manager install_bundle link:<路径>/deep-coo-cloud` → 刷新 DSH 页面
2. **启动 bridge**：复制 `bridge/config.example.json` → `config.json`，填自己的服务器 / SSH / 角色卡 → `node bridge/server.mjs`
3. **设置**：面板「设置 → 通用/连接」填左侧栏名称、桥接地址、服务器 SSH、QQ 白名单（都只存本机）
4. **可选**：桌宠插件、情境观察器、服务器 awareness（见 `INSTALL.md`）
5. **Coo 市场**：浏览/下载 Coo 社区扩展；需要时在 Coopanion 中安装（第三方代码需自行判断）

## 隐私设计

- 本包**不含**任何真实服务器 IP/域名、QQ 号、本机用户路径、SSH 私钥或 token
- 本机私有数据（`settings.json`、`bridge/config.json`、`token.txt`、`server/awareness/config.json`、`coo-pet-data/`）**不进分发包**
- 打包构建后自动扫描：`dist/privacy-report.txt` 必须 `PASS`
- bridge 只监听 `127.0.0.1`；QQ 预览白名单默认空；敏感窗口可标记 private 不注入
- 所有改动可回滚：面板/桌宠可卸载，bridge/observer 删除目录，服务器插件按文档回滚

## 常见问题

**Q：和直接运行 Coopanion 有什么区别？**
A：Coopanion 是桌宠外壳（窗口/渲染/扩展市场）；deep-coo-cloud 给她接上**云端 DSH 人格**，并提供一个统一控制台管理聊天、情境、QQ、桌宠外观与扩展下载。

**Q：必须有自己的云服务器吗？**
A：不必须。`brain: local/session` 也可以只在本机跑；云端模式用于跨设备同一人格与 QQ 共用。

**Q：Coo 市场的扩展能直接在本插件里运行吗？**
A：不能。扩展是 Coopanion（Cortico）的 Worlds/Providers，由 Coopanion 安装运行；本插件负责浏览/下载/指引，不执行第三方代码。

**Q：换服务器/换 QQ 号怎么办？**
A：改本机设置或 `bridge/config.json` 即可；源码里没有写死任何私有值。
